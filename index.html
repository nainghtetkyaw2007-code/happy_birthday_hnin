Memory 01 / 08

၁၉ နှစ်ပြည့် မွေးနေ့မင်္ဂလာပါ 🩵

31.7.2007 ဆိုတဲ့ မင်္ဂလာရှိတဲ့ နေ့လေးမှာ လူ့လောကထဲ ရောက်ရှိလာခဲ့တဲ့ နှင်းအိလှိုင်ရေ... အခုဆိုရင် လှပဆန်းသစ်တဲ့ ၁၉ နှစ်ဆိုတဲ့ အသက်အရွယ်ဆီကို ရောက်ရှိလို့ လာခဲ့ပြီနော်။ ဒီနေ့မှစပြီး မင်းရဲ့ ဘဝမှာ ပျော်ရွှင်စရာကောင်းတဲ့ အမှတ်တရ အသစ်ပေါင်းများစွာကို စတင်ဖန်တီးနိုင်ပါစေ။

Memory 02 / 08

အပြုံးမပျက်တဲ့ ကောင်မလေး ✨

မင်းရဲ့ အပြုံးလေးက ဘေးနားက လူတွေကိုအမြဲတမ်း စိတ်ကြည်နူးစေပါတယ်။ ဘဝမှာ စိတ်ညစ်စရာတွေ၊ အခက်အခဲတွေနဲ့ ကြုံတွေ့လာရရင်တောင်မှ ဒီလို အပြုံးမျိုးလေးနဲ့ပဲ အမြဲတမ်း အနိုင်ယူကျော်ဖြတ်နိုင်ပါစေလို့ ဆုတောင်းပေးပါတယ်။

Memory 03 / 08

အိပ်မက်တွေကို ပုံဖော်မယ့် အရွယ် 🌟

၁၉ နှစ်ဆိုတဲ့ အရွယ်က ကိုယ့်ရဲ့ အနာဂတ်၊ ကိုယ့်ရဲ့ အိပ်မက်တွေကို စတင်ပုံဖော်ရမယ့် တန်ဖိုးရှိတဲ့ အရွယ်ပါ။ မင်း လိုချင်တဲ့၊ ဖြစ်ချင်တဲ့ ရည်မှန်းချက် တိုင်းကိုလည်း မဆုတ်မနစ်တဲ့ ဇွဲနဲ့ အကောင်အထည်ဖော်နိုင်ပါစေ။

Memory 04 / 08

Friendship Day အမှတ်တရ 🤝

၁၂.၅.၂၀၂၅ ဆိုတဲ့ နေ့လေးကတည်းက စတင်ခဲ့တဲ့ တို့ရဲ့ ခင်မင်မှုနဲ့ သံယောဇဉ်တွေက တကယ့်ကို တန်ဖိုးရှိပါတယ်။ ဘယ်လောက်ပဲ အချိန်တွေ ကုန်လွန်သွားပါစေ၊ ရာသက်ပန် အပြန်အလှန် နားလည်ပေးနိုင်တဲ့ သူငယ်ချင်းကောင်းတွေအဖြစ် တည်တံ့နေမှာပါ။

Memory 05 / 08

ကိုယ့်ကိုယ်ကို ဂရုစိုက်ပါ 🍀

သူများတွေကို ဂရုစိုက်တတ်သလိုမျိုး ကိုယ့်ကိုယ်ကိုလည်း အချစ်ဆုံးနဲ့ အဂရုစိုက်ဆုံး ဖြစ်ပါစေ။ အစားမှန်မှန်စား၊ အိပ်ရေးဝဝအိပ်ပြီး စိတ်ရော ကိုယ်ပါ အမြဲတမ်း ကျန်းမာရွှင်လန်းနေဖို့ မမေ့ပါနဲ့နော်။

ဒီနေ့မှာ ကျရောက်တဲ့ မွေးနေ့မှစပြီး အသက် ၁၉ နှစ်မှသည် နောင်နှစ်ပေါင်းများစွာတိုင်အောင် စိတ်ချမ်းသာခြင်း၊ ကိုယ်ကျန်းမာခြင်းတို့နဲ့ ပြည့်စုံပါစေ။

31.7.2007 မှာ မွေးဖွားခဲ့တဲ့ မင်းလေးဟာ ငါတို့အတွက်တော့ အရမ်းကို အဓိပ္ပာယ်ရှိတဲ့ သူငယ်ချင်းတစ်ယောက်ပါ။ ၁၂.၅.၂၀၂၅ Friendship Day ကတည်းက စခဲ့တဲ့ တို့ရဲ့ သံယောဇဉ်ကိုလည်း အမြဲတမ်း မြတ်နိုးတန်ဖိုးထားပါတယ်။

ရှေ့ဆက်မယ့် လမ်းခရီးမှာ အဆင်မပြေတာတွေ ကြုံလာခဲ့ရင်တောင် အမြဲတမ်း အားတင်းထားပါ။ မင်းရဲ့ အောင်မြင်မှုနဲ့ ပျော်ရွှင်မှုတိုင်းကို အဝေးကနေ အမြဲတမ်း ဂုဏ်ယူဝမ်းမြောက်စွာနဲ့ စောင့်ကြည့်အားပေးနေမှာပါ။ မွေးနေ့မှာ ပျော်ရွှင်ပါစေ မွေးနေ့သူလေးရေ! 🎂🎈✨
